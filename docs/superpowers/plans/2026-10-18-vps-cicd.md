# Smart Agri VPS CI/CD Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Validate PRs, publish immutable SHA-tagged images for the four production services, deploy them to a configured VPS, and retain a safe rollback path.

**Architecture:** Extend the existing CI workflow rather than adding duplicate test jobs. Publish only the services already enabled in production Compose, then use a protected production environment and pinned actions to transfer only deployment files and invoke a remote script over verified SSH. The remote script pulls and validates all images before updating containers, waits for health, records release state, and attempts a previous-release rollback on failure without touching volumes.

**Tech Stack:** GitHub Actions, Maven, Docker Buildx, GHCR, Docker Compose v2, OpenSSH, Bash.
